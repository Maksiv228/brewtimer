# Brew Timer

Клиентский мод для Minecraft 26.2 (Fabric): таймеры варки и выдержки для серверов с плагином BreweryX.

## Котёл

- Кидаете первый ингредиент в котёл с водой — запускается таймер.
- Мод считает ингредиенты (по одному за клик) и подбирает рецепт из стандартных рецептов BreweryX.
  Над хотбаром видно, что получается: «Джин — не хватает: Яблоко ×1».
- Когда рецепт распознан, идёт обратный отсчёт до нужного времени варки.
- Набираете напиток пустой бутылкой — в чат пишется, точно ли вы попали во время, и что делать дальше
  (сколько циклов дистилляции, какая бочка и сколько лет).
- Shift + ПКМ пустой рукой по котлу — сбросить таймер.

## Бочка

- Положите напитки в бочку BreweryX и закройте её — мод запомнит, что и когда положено.
- Рецепт определяется по названию напитка, а если не получилось — по последней варке.
- Отсчёт идёт до нужного числа лет (1 год = 20 минут, меняется в `Recipes.MINUTES_PER_YEAR`).
- При каждом открытии бочки мод уточняет возраст напитков:
  1. из скрытых данных BreweryX (`breweryx:brewdata`) — точно, если на сервере выключено шифрование (`enableEncode: false`, по умолчанию);
  2. иначе из строки «N лет … в бочке» в описании — до ±10 минут;
  3. иначе считает от момента, когда напиток положили.
- Забрали напитки и закрыли бочку — таймер пропадает.
- Таймеры бочек сохраняются в `config/brewtimer-barrels.json` и переживают перезапуск игры.

## Экран

- В правом нижнем углу видны только таймеры, которым осталась минута или меньше (жёлтые)
  и просроченные (красные).
- Все таймеры — в окне по клавише **B** (меняется в Настройки → Управление → «Таймер варки»).
  Там же подробности и кнопка ✕, чтобы удалить таймер.
- За минуту до готовности звучит колокольчик, в момент готовности — сигнал и сообщение в чат.

## Отладка

Клавиша **J**: возьмите напиток в основную руку и нажмите — мод напишет в чат, что смог прочитать,
и допишет полный отчёт (все компоненты предмета) в `config/brewtimer-debug.txt`.

## Ограничения

- Мод видит только ваши клики: ингредиенты, которые кинул другой игрок, не учитываются.
- Таймер варки считает от первого ингредиента. Варка в BreweryX идёт только при огне под котлом,
  поэтому зажигайте его заранее.
- Рецепты стандартные. Если на сервере их изменили, правьте таблицу в `Recipes.java`.

## Сборка

Нужен JDK 25 (например, Eclipse Temurin 25) и интернет.

```
gradlew.bat build
```

Готовый мод появится в `build/libs/brewtimer-1.2.1.jar`. Положите его в папку `mods` вместе с Fabric API для 26.2.
